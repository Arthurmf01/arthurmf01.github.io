Build · running daily since August 2026

Ambidex

Speak a thought into my phone. It lands as a task in my notes, and an agent drafts the next step for me to approve.

Stack
Cloudflare Workers · Whisper (Groq, Workers AI fallback) · GitHub API · headless AI coding agent · Telegram
Runs
Every capture; the agent checks for new work every two minutes
Code
github.com/Arthurmf01/ambidex (architecture and design notes; the live code stays private)

Why it exists

I had ideas and to-dos all day, between classes and on the move, and lost most of them. Typing on a phone is slow, and a note app only stores things; it does not do the next step. I wanted one button: speak, and the follow-up starts without me.

How it works

  1. On the phone, a web app with one large button. I tap and speak.
  2. The audio goes to a Cloudflare Worker and is transcribed by Whisper in a second or two. I check the text, then save.
  3. The task is written into my Obsidian notes on GitHub, the single source of truth.
  4. If I tag it for the AI, an agent on my Mac picks it up, runs an AI coding agent headless and sorts it: outreach, research, a lookup, a draft.
  5. It writes a draft in a fixed place (a follow-up list, a research note) and pings me on Telegram.
  6. Nothing is sent on my behalf. I approve, edit or bin each draft.

What I learned

Capture was never the hard part. Finding things again, and closing the loop, was. That is why the morning Daily Brief came next. And an agent should not grade its own work: every build now has a separate reviewer agent that tries to break it before I see it.
